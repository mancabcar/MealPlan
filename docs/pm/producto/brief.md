# MealPlan: el producto completo (PRD)
_Status: tech design · Updated: 2026-11-13 · Spec: [spec.md](spec.md) · Tech: [tech.md](tech.md)_

## Problem
Seguir un plan nutricional exige hoy varias herramientas sueltas: una app de macros, notas para el plan semanal, una lista de la compra aparte y la memoria para saber qué caduca en la nevera. MealPlan las junta en un solo ciclo. Hasta ahora se ha construido feature a feature (unas 40 specs en `docs/pm/`), sin un documento que describa el producto entero ni hacia dónde va.

## Bet
Un PRD de producto que hace dos cosas: fija la línea base de lo que ya existe (todo `Must`, enlazado a sus specs de feature) y define la visión para abrir el producto a cualquiera: registro abierto, monetización freemium, traducción al inglés y apps en las tiendas.
